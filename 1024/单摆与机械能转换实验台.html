HEIGHT / 高度

升得越高，存下的势能越多

以最低点为零势能位置，h = L(1 − cos θ)，Eₚ = mgh。无阻尼时下落减少的势能，转化为摆球的动能。

PERIOD / 周期

小角度时，摆长决定节奏

小角度近似下 T₀ = 2π√(L/g)，与质量无关。角度较大时周期会变长；本模型保留 sin θ，使用非线性运动方程。

FORCE / 力

最低点很快，加速度并非零

理想模式下，最低点的切向加速度为零，仍有向心加速度 v²/L，张力 T = mg + mv²/L。有阻尼时，最低点还存在与运动方向相反的切向加速度。

QUICK START / 一页使用说明

从一次摆动开始

  1. 先设置：调节摆长、质量和初始角度；改变参数会从静止重新开始。
  2. 再释放：点击“释放并播放”，或直接拖开摆球后松手。再次点击按钮可暂停观察。
  3. 对照看：观察摆球、能量条和读数。选择“最低点”可跳到理想摆动经过最低点的真实状态。
  4. 做比较：每次只改变一个参数，记录最多 4 组实验，下载后用于讨论。

课堂与慢放

“课堂模式”集中显示实验台；全屏可进一步放大。慢放只改变播放速度，读数仍按模拟时间计算。

为什么没有动？

初始角为 0° 时，摆球静止在最低点。先拖开或增大角度。系统开启“减少动态效果”时，手动点击播放仍然可用。

键盘也能操作

先点一下模型：← → 调角度，空格 播放或暂停，Home 恢复，Esc 暂停。

离线使用

下载离线教学版，用浏览器打开 HTML 文件即可。无需安装开发工具。关闭页面前，请下载需要保留的实验记录。

理解模型：摆长是悬点到球心的距离；最低点为重力势能零点。轻绳不可伸长，摆球视为质点。无阻尼时机械能守恒；阻尼使机械能逐渐转化为内能等其他形式。
